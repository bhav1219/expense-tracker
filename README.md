# Expense Tracker

A simple Expense Tracker web application built using Flask and SQLite.

## Features
- Add daily expenses
- Categorize expenses
- Set a monthly budget
- Track total expenses
- View monthly expense history
- Check remaining budget

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## How to Run
1. Clone this repository.
2. Install Flask:
   pip install flask
3. Run the application:
   python app.py
4. Open the local URL shown in the terminal.

## Purpose
This project helps users manage daily expenses and monitor their monthly budget.
